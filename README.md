# Lab Skeleton

## Cách dùng

1. Đổi tên repo theo quy tắc trong `SUBMISSION.md`.
2. Điền nội dung trong `README.md`, `CHECKPOINTS.md` và `RUBRIC.md`.
3. Có 2 loại bài nhóm và cá nhân:
   - Cá nhân: dùng `report/individual/MSSV_HoTen.md`.
   - Nhóm: dùng `TEAM.md` (root), `report/team/group_report.md` và một báo cáo `report/team/MSSV_HoTen.md` cho mỗi thành viên.
4. Đảm bảo repo clean học viên dễ tiếp cận

## Cấu trúc

- `src/`: source code học viên thực hiện.
- `TEAM.md`: khai báo thông tin nhóm ở root.
- `report/individual/`: template báo cáo cá nhân.
- `report/team/`: báo cáo nhóm và báo cáo từng thành viên.

Tên báo cáo cá nhân phải được đổi thành:

```text
report/individual/MSSV_HoTen.md
```

Ví dụ: `report/individual/20241234_NguyenVanAn.md`.
